# I built this site with Next.js

Before starting to write in this diary, I spent a few days building it. Here's a look at how I did it.

## Why build my own site?

I could have used Medium, Substack, or a simple WordPress blog. But I wanted something truly personal, that I fully control.

It's also an excuse to code a fun project during the holidays. 😄

## The tech stack

```javascript
const stack = {
  framework: 'Next.js 15',
  styling: 'Tailwind CSS + shadcn/ui',
  content: 'Markdown + gray-matter',
  i18n: 'Français, English, 日本語'
};
```

### Why Next.js?

- **App Router** — The new way to structure React apps
- **Server Components** — Optimal performance
- **Easy deployment** — A `git push` and it's live

## What I learned

This project reminded me why I love coding. There's something satisfying about creating something from scratch, even if it's "just" a blog.

The hardest part? Choosing colors. Seriously, I spent more time on the color palette than on the code. 🎨

# J'ai créé ce site avec Next.js

Avant de commencer à écrire dans ce journal, j'ai passé quelques jours à le construire. Voici un aperçu de comment j'ai fait.

## Pourquoi créer mon propre site ?

J'aurais pu utiliser Medium, Substack, ou un simple blog WordPress. Mais je voulais quelque chose de vraiment personnel, que je contrôle entièrement.

C'est aussi une excuse pour coder un projet fun pendant les vacances. 😄

## La stack technique

```javascript
const stack = {
  framework: 'Next.js 15',
  styling: 'Tailwind CSS + shadcn/ui',
  content: 'Markdown + gray-matter',
  i18n: 'Français, English, 日本語'
};
```

### Pourquoi Next.js ?

- **App Router** — La nouvelle façon de structurer les apps React
- **Server Components** — Performance optimale
- **Facilité de déploiement** — Un `git push` et c'est en ligne

## Ce que j'ai appris

Ce projet m'a rappelé pourquoi j'aime coder. Il y a quelque chose de satisfaisant à créer quelque chose from scratch, même si c'est "juste" un blog.

Le plus dur ? Choisir les couleurs. Sérieusement, j'ai passé plus de temps sur la palette de couleurs que sur le code. 🎨

## TL;DR

**プラグイン**は、1 つのワークフローに Claude が必要とするもの一式（スキル、スラッシュコマンド、MCP コネクタ、設定）をまとめたもので、ワンクリックでインストールできる。コースでのたとえは、**スキルはレシピ、プラグインはシェフ**。たくさんのレシピを知り、適切な道具がつながっているシェフだ。

| | スキル | プラグイン |
|---|---|---|
| 何か | 1 つのタスクのステップごとの指示 | 1 つの領域全体のためのインストール可能なバンドル |
| 中身 | `SKILL.md`（+ リファレンス、スクリプト） | スキル + コマンド + MCP サーバー + 設定 |
| 外部データ | 不要 | アプリへのライブ接続 |
| 共有 | ファイルをアップロード | マーケットプレイス、バージョン管理、チーム展開、スコープ付き権限 |

「スキルは頭脳、プラグインは身体。」

## プラグインを使う

**Customize → Plugins** を開いて 1 つ選び（例えば *Customer support*）、説明と **"Try asking"** の例を読む。**コマンド**で起動する。サイドパネルには、どのコマンドとコネクタが使われたかが表示される。

## プラグインをカスタマイズする

1. ⋯ → **Show in folder** でプラグインの `commands/` と `skills/` フォルダが開くので、ファイルを編集、追加、削除する。何か削除した後は **Claude の再起動**が必要。
2. **Customize** ボタンを押すとチャットが開く。まず「このプラグインにあるコマンドとスキルをすべて一覧にして」と頼み、それから自社向けに調整していく。

## プラグインをインポートする

**Add plugin** から次のいずれかを選ぶ：
- **Browse plugins**（Anthropic 製）。**Personal** タブも含む。
- **Upload plugin**（ファイルをドラッグ＆ドロップ）。
- **Add marketplace from GitHub or URL**：リポジトリ URL かマーケットプレイスの JSON を貼り付けて **Sync**。例：公開リポジトリにある財務分析プラグイン。

## プラグインを作る

一番簡単なのは「プラグインを作って」と頼むこと。Claude がスキルとコマンドを一緒に考えてくれる。コースにはプロンプトを書いてくれるフォーム形式のヘルパーもある。入力するのは名前、目的、ユーザー、カテゴリ、そして 2〜3 個のスキル（それぞれトリガー、指示、出力フォーマット付き）。

## 見ておきたい Anthropic のプラグイン

**Data**（インタラクティブな HTML ダッシュボードとデータ Q&A）、**Marketing**、**Customer support**、**HR**、**Engineering**、**Operations**、**Sales**。

## 演習

単一のタスクではなく**テーマ**を軸にプラグインを設計する。例えば、記事下書き、コンテンツの再活用、フック作成のスキルを持つコンテンツ用プラグイン。それらのスキルがなぜ一緒にあるべきかを説明する。

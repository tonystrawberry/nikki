## TL;DR

**Claude Cowork** は Claude デスクトップアプリに入っている。普通のチャットボットはアドバイスするだけだが、Cowork は**実際に動く**。ファイルのリネームや整理、レポート作成、ブラウザ操作、ワークフローの定期実行までこなす。実行力は Claude Code と同じだが、ターミナルもコードも不要なビジュアルアプリで使える。

| | Claude Code | Claude Cowork |
|---|---|---|
| インターフェース | CLI / IDE | デスクトップアプリ（ビジュアル） |
| 対象ユーザー | 開発者 | ファイルやアプリを扱うすべての人 |
| 作業対象 | コードベース、git、ターミナル | フォルダ、ドキュメント、ブラウザ、アプリ |

## セットアップ

- claude.com/download からデスクトップアプリをダウンロードしてサインインする。Cowork は有料プランが必要。
- アプリを **Chat** から **Cowork** に切り替える。

## フォルダでの作業

フォルダへのアクセスを許可し、やってほしいことを普通の言葉で伝える：

```text
請求書フォルダ内のすべてのファイル名の先頭に請求日を付けて
リネームしてください（YYYY-MM-DD_...）。
```

Claude はファイルをスキャンし、中身からそれぞれの日付を抜き出し、すべてリネームして結果を確認する。命名規則やフォーマットがバラバラでも対応できる。

コースで紹介されたその他の例：
- 長い動画から **10 秒のタイムラプス**を切り出す。
- レシートのフォルダからサマリーを作る。
- ブランド素材のフォルダからダウンロード可能な **PPTX** を作る。
- 複数のタスクを**キューに入れ**、実行中も自分は別の作業を続ける。

> Cowork が真価を発揮するのはタスクが大きいときだけ。3 ファイルのリネームならやる価値はないが、300 ファイルなら話は別だ。

## ブラウザタスク（Claude in Chrome）

- **Claude in Chrome** 拡張機能をインストールし、同じアカウントでサインインする。
- デスクトップアプリか拡張機能から「ブラウザでやって」とタスクを始める。
- タスクごとに専用の **Chrome タブグループ**が作られ、ワンクリックで閉じたり開き直したりできる（詳しくはセクション 9）。

## Claude に教えて、スケジュールする

**Teach Claude** は Chrome 拡張機能でのみ使える。*Start recording* を押し、マイクで説明しながらタスクを実演すると、Claude がそれを**ショートカット**として保存する。

- `/shortcut-name` で再実行。
- ⋯ → Settings → Shortcuts で編集。
- **スケジュール**設定も可能。例：毎週月曜に「LinkedIn Posting」シートを読み、投稿を公開する。

## コネクタ（MCP）

Customize → **Connectors**（Skills や Plugins と並んでいる）にある。Gmail、Notion、Slack、Canva、Figma、HubSpot、Google Calendar 用は既製のものがある。それ以外は **Add custom connector** でアプリの MCP サーバー URL を指定する。

```text
Gmail で私が送った直近 10 通のメールを取得し、私の文体とトーンを
説明する PDF を作成してください。
```

この PDF は後で、自分の文体でメールを下書きする**スキル**の材料になる。Claude は適切なコネクタを自分で選ぶが、選ばない場合は「Gmail コネクタを使って」と言えばいい。

## Computer use と Dispatch

- **Computer use**：許可した 1 つのフォルダやブラウザだけでなく、マシン全体（アプリ、マウス、キーボード）を Claude が操作する。
- **Dispatch**：**スマホから**デスクトップの Cowork にタスクを送る。ファイルアクセスと「コンピュータをスリープさせない」をオンにしておかないと、スリープ中はタスクが実行されない。講師のアドバイスは、そのマシンに機密ファイルを置かないこと。

## ボーナス：Cowork でウェブサイトを作る

**Project** を作成する。Project はファイル、指示、ローカルフォルダをチャット間で共有できる。ウェブサイト要件のテンプレートを貼り付けて Claude の質問に答えると、サイト構成一式を生成してくれる。あとはホスティングするだけ。

## 演習
1. 散らかったフォルダを整理し（日付別、種類別、重複削除）、ビフォーアフターを比較する。
2. ブラウザエージェントで実際のタスクをこなす。
3. 繰り返し作業のワークフローを Claude に教え、ショートカットを実行する。

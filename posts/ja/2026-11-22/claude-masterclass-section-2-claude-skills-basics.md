## TL;DR

Claude はたいていのタスクのやり方をすでに知っている。ただし**自分の**やり方は知らない。**スキル**は普通の言葉で書かれたオンボーディングガイドで、手順、品質基準、フォーマット、トーン、専門知識をまとめたものだ。Claude にスキルを足せば、**一貫した**アウトプットを出すオンデマンドの専門家になる。スキルはチームで共有もできる。

## スキルを使う

- **Customize → Skills** を開き、使いたい Anthropic のスキル（canvas design、doc co-authoring など）をオンにする。
- スキルをインポートするには **+ → Upload** をクリックし、`.md`、`.zip`、またはフォルダをドラッグする。
- コースでは 20 以上のスキルパックが配布されている。フックエンジニア、メモ→PowerPoint、CTA オプティマイザー、ドキュメントコンバーターなど。

## スキルの構造

```text
my-skill/
├── SKILL.md        # 必須：役割、ロジック、判断ルール、ワークフロー
├── scripts/        # 任意：データ処理や API 呼び出しなどの Python
└── references/     # 任意：ガイド、例、ドメインのドキュメント
```

必要なのは `SKILL.md` だけ。フロントマターの `description` が、スキルの用途と使うタイミングを Claude に伝える。

## 作り方は 3 通り

1. **Skill Creator**：スキルを作るための Anthropic 公式スキル。チャットしてリファレンスを添付すると、質問しながら作ってくれる。コード不要で最も簡単。
2. **手動**：`SKILL.md` とフォルダを自分で書いてアップロードする。
3. **Claude Code**：プロジェクトの `.claude/skills/` で作る（セクション 3）。

ドキュメントをスキルに変換するためのテンプレート（要約）：

```text
添付した <ドキュメント名> を確認し、<目的> のための再利用可能な
Claude スキルに変換してください。
始める前に、必要なブランド／コンテキストのファイルがすべて含まれているか確認し、
重要な情報が欠けていれば作業を止めて、短く具体的な質問をしてください。
ドキュメントのステップごとの手順に厳密に従ってください。
構造とフォーマットが正しくなるよう、skill-creator スキルを使ってください。
```

コツ：*テンプレートを埋めるだけで、まだスキルは作らないで*と Claude に頼むこと。そうしないと、スキルを作るためにスキルを実行してしまうことがある。

## スキルを編集する

- チャットで「このファイルで `<skill-name>` スキルを更新して…」と言う。新しい会話ではスキル名を明示する。
- または ⋯ → **Download** でファイルを落とし、編集して再アップロードする。

## 例：「世界ニュース」スキル

チャットで作成。Skill Creator がトピック、フォーマット、記事数について質問し、その後**スキルあり・なしで eval を実行**した。合格率は **93% 対 55%**。

## スキルの探し方

skillhub.club、skillsmp などのマーケットプレイス（有料のものもある）。ネットで拾ったスキルは調整が必要なこともあるので、「このスキルを Claude に対応させて」と Claude に頼む。

## 演習
1. 組み込みスキルを 1 つオンにして使ってみる。
2. 好きな方法で最初のスキルを作る。
3. 任意：方法ごとに 1 つずつ、計 3 つのスキルを作る。

## TL;DR

**Claude Design** は claude.ai のサイドバーから開く Anthropic の独立した製品で、自然言語からプロ品質のデザインを生成する：ランディングページ、SNS コンテンツ、アプリのプロトタイプ、スライド資料、3Dビジュアル。強みは**デザインシステムによる一貫性**と素早い反復。弱点は**別枠の週次利用上限**で、すぐに使い切ってしまう。

## プロジェクトの作成

プロジェクトを始めて種類を選ぶ：**Prototype**（一番よく使う）、**Slide deck**、**From template**、**Other**。Prototype には2つの忠実度がある：
- **Wireframe**：構造をざっと作る。
- **High fidelity**：本番レベルの仕上がり。

画面は左がチャット、右がライブプレビュー。ファイルを添付でき、**Sketch** で欲しいレイアウトを手描きすることもできる。

## デザインシステム：最初に用意する

デザインシステムとはブランドのルールのこと：ロゴ、フォント、色、ボタン、レイアウト、コンポーネント。一度作って新規プロジェクトごとに選択すれば、どの資料もページも見た目が揃い、スタイルを毎回説明し直す必要がなくなる。**Share** から ZIP でエクスポートできる。

デモのブランドは「Knight Firm」という架空のウェアラブル。同じシステムから**スライド資料**（素材、バッテリー、防水性、価格）と、注文ボタンつきの**ランディングページ**が作られた。

## テンプレート

- **Share → Duplicate as template** で組織向けに公開し、**New from this template** で使う。
- **Examples** タブには既製のテンプレートがある。

## 講座で紹介された使い方

- 素っ気ない Google ドキュメントを洗練された **PDF** に作り直す。
- サイトの HTML を**プロモ動画**や**アニメーションつきグラフ**にする（詳細なプロンプトのほうがずっとうまくいくので、まず Claude に詳しいプロンプトを書かせる）。
- 軌道、ホバー時のラベル、時間スケール調整つきの**インタラクティブな 3D** 太陽系を作る。これがセクションの課題だった。
- 最終プロジェクト：**ゼロから作って Vercel にデプロイする完全な Web サイト**。
- **モバイルアプリのプロトタイプ**：Claude Design で設計して ZIP をエクスポートし、VS Code の **Claude Code** にすべてのボタンとタブをつなげさせる。デザイナー、そして開発者。

## トークン、上限、コツ

- **Settings → Usage** を確認する。Claude Design には**独自の週次上限**があり、Pro は Max よりずっと少ない。複雑なアプリ1つで上限の 40〜50% を使うこともある。
- **Claude Design でブレストしない。** 通常のチャットで考え抜いてから、正確なプロンプトを持ってくる。
- **指示は最後に置く**。すべてのコンテキストの後に。
- ⚙️ アイコンでプロジェクトごとにモデルを選べる：Haiku 4.5、Sonnet 4.6、Opus 4.7。
- 別タブで**複数のプロジェクトを並行して**動かせる。

## 無料の代替：Open Design

**Open Design** はオープンソースのローカル版クローンで、スター数 4万以上、数十の Skills とデザインシステムを備え、Web、モバイル、スライド、画像、動画のプロトタイプに対応する。Claude Code でプロンプト1つでインストールでき、**自分の API キーを使う**（OpenAI など）ので、上限は自分のモデル利用量だけになる。
